Запусти конвейер сверки recono по аргументам пользователя: $ARGUMENTS

Правила разбора аргументов:

- Первый обязательный аргумент — дата в формате `YYYY-MM-DD`.
- Второй необязательный — конвейер: `providers` (по умолчанию), `merchants`, `balances`, `all`.
- `--provider=<slug>` ограничивает провайдерский конвейер одним провайдером.
- `--process=<id>` продолжает работу с конкретным процессом мерчанта или баланса.
- Если дата не указана или формат неверный — не запускай команды, а попроси дату.

Передай разобранные параметры субагенту `reconciliation-orchestrator` из этого плагина.
Агент сам проверит статусы, пройдёт гейты и вернёт отчёт. Покажи пользователю отчёт агента
целиком, не пересказывая его своими словами.

Если пользователь просит только диагностику («почему висит», «что с процессом»), не запускай
стадии — попроси агента собрать статусы, логи и ошибки и предложить следующий шаг.
